# Задачи проекта Kodium Academy

После каждого этапа — остановка и вопрос пользователю о дальнейших действиях.
Порядок: сначала весь сайт и дизайн, затем RAG, файлы и Google Drive.

## Сайт и дизайн
- [x] **Этап 1. Фундамент** — Next.js + Tailwind, CLAUDE.md, tasks.md, пустая папка `knowledge/`, `.env.example`.
- [x] **Этап 2. Дизайн-система** — палитра (тёмная + золото), Unbounded и Onest, Button/Badge/Card/Section.
- [x] **Этап 3. Главная страница** — шапка, Hero, направления, каталог с фильтром, преимущества, процесс, преподаватели, отзывы, FAQ, форма заявки, футер.
- [x] **Этап 4. Страница курса** — `/courses/[slug]` на тестовых данных из `src/lib/courses.ts` (404 для несуществующих).
- [x] **Этап 5. UI AI-ассистента** — плавающая кнопка, панель чата, подсказки, состояние загрузки. Ответы пока заглушка.
- [ ] **Этап 6. Доработка сайта** — правки по обратной связи, проверка на мобильных, анимации, фавикон/OG-картинка, отправка заявок (куда — решить).

## RAG, файлы, данные (после утверждения сайта)
- [x] **Этап 7. Курсы из Excel** — `getCourses()` читает `knowledge/courses.xlsx`; добавили строку — курс появился, удалили — пропал.
- [x] **Этап 8. RAG-бэкенд (без БД)** — `@google/genai`, `/api/chat`: чтение `knowledge/`, чанки, эмбеддинги в памяти, top-k, ответ Gemini по контексту; подключение к ChatWidget. Нужен `GEMINI_API_KEY` в `.env.local`; ответы Gemini ещё не проверены с реальным ключом.
- [x] **Этап 9. Форматы файлов** — md/txt/pdf/docx/xlsx в `loadDocuments()`; примеры документов.
- [x] **Этап 10. Google Drive** — `listKnowledgeFiles()` читает папку Drive через сервисный аккаунт, если заданы `GOOGLE_DRIVE_FOLDER_ID` и ключ; иначе локальная `knowledge/`. Проверено на подставном API, с настоящим Drive ещё нет.
- [ ] **Этап 11. SEO и деплой** (Vercel).
